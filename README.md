# NITROVOLT

A browser time-attack racer: instant restarts, short punchy tracks, ghosts, medals, jumps and a built-in track editor.
Everything is generated in code (cars, tracks, scenery, sky, textures, engine sounds and music), with no external assets.
It is an original game and not affiliated with any other racing title.

**Status: 1.0.0, all 8 phases complete.** Installable and playable offline (PWA), deployable as a static site.

## Features

- **Four cars, one physics core**: a custom 100 Hz raycast-suspension vehicle with a per-surface tyre model; Volt (stadium), Gravel (rally), Frost (snow / ice), Dune (sand). Rapier handles only collision queries.
- **100-level campaign** in four seasons (Metro, Alpine, Desert Canyon, Coast & Harbour): 7 hand-made levels plus 93 generated by a seeded level generator and validated by a bot ([`docs/LEVEL_REPORT.md`](docs/LEVEL_REPORT.md)). Bronze unlocks the next track, medal points open later seasons.
- **Medals and exact ghosts**: Author / Gold / Silver / Bronze; ghosts are the recorded input stream re-simulated bit-exactly (PB and author ghosts, replay viewer with free camera).
- **Special blocks**: turbo, turbo 2, reactor, no-steer, no-brake, cruise, engine off, slow motion, low gravity, fragile; loops, half-pipes, wall-rides, spirals, jumps.
- **Track editor**: palette, chain building, live checks, test drive, bot validation, My tracks, share links that carry the whole track.
- **Look and sound**: a clean, modern daylight look: four themes with procedural sky, ground and instanced scenery (glass-and-concrete city, alpine, desert, harbour), smooth lofted car bodies with clear-coat paint, anti-aliased road markings, skid marks and sparks; a generative soundtrack per season and a synthesised engine per car.
- **Every input**: keyboard (remappable), mouse steering, gamepad (analog, rumble), touch with tilt steering; full keyboard / gamepad menu navigation.
- **Accessibility**: HUD size, colour-blind medal palette (medals also differ by shape), reduced motion, unlock everything, countdown length.
- **Performance**: quality presets with an automatic benchmark and dynamic resolution; physics and editor load on demand.

## Run

```bash
npm install
npm run dev        # dev server at http://localhost:5173
npm test           # 152 unit / integration tests (FULL=1 drives all 100 levels)
npm run build      # typecheck + static build in dist/ (BASE_PATH=/sub/path/ for a sub-path)
npm run preview    # serve dist/
npm run campaign   # regenerate + validate the 100 campaign levels and docs/LEVEL_REPORT.md
npm run icons      # regenerate the PWA icons in public/icons/
```

Dev flags: `?debug=1` (tuning panel + debug HUD + `window.__nv`), `?level=<id>`, `?track=flat|greybox`, `?car=<id>`, `?autodrive=1`, `?quality=low|medium|high|ultra`.

| --- | --- | --- | --- |
| Accelerate / brake-reverse | W S / Up Down | RT / LT | GAS / BRAKE |
| Steer | A D / Left Right (or mouse, `M`) | Left stick, D-pad | arrows or tilt |
| Restart | Enter | Start | RESTART |
| Respawn | Backspace | Y | RESPAWN |
| Camera | C | A | camera button |
| Pause menu / back | Esc / P | Back (B in menus) | menu button |
| Ghost cycle | G | | |
| Replay (finish screen) | V | | |
| Menu navigation | arrows, Enter, Esc | D-pad / stick, A, B | tap |

The editor has its own shortcuts (see *How to play* in the game, or [`docs/PHASE_7.md`](docs/PHASE_7.md)).

## Deploy

`.github/workflows/pages.yml` tests, builds with `BASE_PATH=/<repo>/` and publishes `dist/` to GitHub Pages on pushes to `main`
(enable *Settings > Pages > Source: GitHub Actions* once). The build is fully static: a service worker precaches the game for
offline play, and share links keep their data in the URL hash, so no server is needed. See
[`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md) before publishing.
